Data Structures and Algorithms

Fundamental data structures and algorithms in C++.

Term: Fall

A 12-week course on fundamental data structures and algorithms in C++. Each week has a 2-hour lecture and a 1.5-hour tutorial.

Lecture notes and course materials are posted in the schedule below as the course progresses.

Schedule

Week Date Topic Materials
1 C++ Basics

Types, variables, control flow, functions · references vs values: pass-by-value, pass-by-reference, pass-by-const-reference · classes: members, constructors, access specifiers · std::vector as a user (not implementer)
2 Pointers, Dynamic Memory, RAII

Pointers: addresses, dereference, nullptr · dynamic memory: new / delete, heap vs stack · RAII: destructors and resource ownership · a brief look at C-style arrays · header files and the compilation model
3 Templates, Iterators, and Big-O

Function templates and class templates · iterators: the abstraction and its categories · Big-O notation: definition, common growth rates, why we care · worked example: amortised analysis of push_back
4 Linked Lists and Recursion

Recursion: base case, recursive case, the call stack · singly linked lists: traversal, insertion, deletion · linked list vs vector: when O(1) vs Ω(n) matters in practice · recursion on linked structures
5 Hash Tables, Stacks, and Queues

Hash tables: hashing, collisions, chaining, expected O(1) lookup · stacks and queues: LIFO/FIFO, typical use cases · std::unordered_map, std::stack, std::queue as users
6 Sorting and Divide-and-Conquer

Insertion sort and why it’s O(n²) · the divide-and-conquer paradigm · mergesort: algorithm, recurrence, O(n log n) analysis · quicksort: partition, average vs worst case
7 Binary Trees, Traversals, and BSTs

Binary trees as a recursive structure · preorder, inorder, and postorder traversals · binary search trees: invariant, insertion, search · inorder traversal of a BST yields sorted output
8 Heaps and Priority Queues

Binary heaps: array representation, heap property · push and pop (sift up, sift down) · priority queues: the abstraction, when to reach for one · std::priority_queue as a user
9 Graphs: Representations, BFS, and DFS

Graph representations: adjacency list vs adjacency matrix · directed vs undirected, weighted vs unweighted · BFS and unweighted shortest paths · DFS as the natural traversal companion
10 DFS Applications: Cycle Detection and Topological Sort

DFS with colours, discovery and finish times · cycle detection in directed graphs · topological sort via DFS finish order and Kahn’s algorithm · DAGs and why they’re special
11 Shortest Paths: DAG Shortest Paths and Dijkstra

Shortest paths on a DAG by relaxing edges in topological order · why this fails on graphs with cycles · Dijkstra’s algorithm and the priority queue insight · correctness intuition, complexity analysis
12 Dynamic Programming (Intro)

DP as recursion + memoisation · top-down (memoised) vs bottom-up (tabulated) formulations · overlapping subproblems and optimal substructure · connection back to DAG shortest paths · full treatment continues in Advanced Algorithms
