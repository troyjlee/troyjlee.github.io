Flow Networks

Setting A directed graph $G=(V,E)$ with a capacity $c(e) \ge 0$ on each edge, a source $s$ and a sink $t$.

Think of routing water, traffic, or data from $s$ to $t$.

st-Flows

Definition An st-flow assigns a value $f(e) \ge 0$ to each edge such that:
  • Capacity: $f(e) \le c(e)$ for every edge $e$,
  • Conservation: for every vertex $v \ne s,t$: $\displaystyle\sum_{e \in \delta^-(v)} f(e) \;=\; \sum_{e \in \delta^+(v)} f(e)$

$\delta^-(v)$ = edges entering $v$,   $\delta^+(v)$ = edges leaving $v$. Flow in equals flow out, except at the source and the sink.

One valid flow always exists: the zero flow $f \equiv 0$. We want the opposite extreme.

The Value of a Flow

Definition The value of $f$ is the net flow out of the source: $|f| = \displaystyle\sum_{e \in \delta^+(s)} f(e) - \sum_{e \in \delta^-(s)} f(e)$.
Problem Maximum flow: find an st-flow of maximum value.

By conservation, everything leaving $s$ must arrive at $t$ (we will prove a sharp version of this later: the value equals the net flow across any st-cut).

Example: a Flow of Value 19

$|f| = 12 + 7 = 19$. Is this the best possible? How would we even know?

Flow Decomposition

Theorem Any st-flow $f$ can be written as a sum of flows along at most $|E|$ st-paths and cycles.

A flow can also contain cycles — flow going round in circles — which contribute nothing to the value.

Flow Decomposition

Our value-19 flow decomposes as

  • $12$ units on the path $s \to 1 \to 3 \to t$,
  • $7$ units on the path $s \to 2 \to 4 \to 3 \to t$.

Flow Decomposition: Proof Sketch

Phase 1. While $|f| > 0$: starting at $s$, follow positive-flow edges — conservation means we never get stuck before reaching $t$. Subtract the bottleneck value of the st-path found.

Phase 2. When $|f| = 0$ but some edge still carries flow: following positive-flow edges from it must eventually revisit a vertex — a cycle. Subtract its bottleneck.

Flow Decomposition: Proof Sketch

Each step zeroes out at least one edge, so there are at most $|E|$ steps. $\blacksquare$

Takeaway Flows look complicated, but they are just paths plus cycles. Max flow is really about finding good path packings.

Ford-Fulkerson and Residual Graphs

A Greedy Attempt

Natural idea: repeatedly find an st-path with spare capacity and push as much flow as possible along it. Start with the widest path: the one whose bottleneck, its smallest edge capacity, is largest.

Greedy Gets Stuck at 18

Continue: push $5$ along $s \to 1 \to t$, then $5$ along $s \to 4 \to t$.

$|f| = 8 + 5 + 5 = 18$. Is there another st-path with spare capacity?

Greedy Gets Stuck at 18

Four edges are saturated, $f(e) = c(e)$: they can carry nothing more, so remove them.

From $s$ we can still reach $1$ and $3$, but not $t$: no st-path is left. Greedy stops at $|f| = 18$.

But 18 Is Not Optimal

Careful The maximum flow in this network has value $21$. Greedy path-packing can get stuck at a suboptimal flow — early paths make commitments that later paths cannot work around.

What went wrong: the $8$ units on edge $2 \to 3$ hog capacity that is needed on $3 \to t$; vertex $4$ would happily take flow from $2$ instead.

The fix: allow a new path to decrease flow on an edge, i.e. to undo earlier decisions.

The bookkeeping device for this is the residual network.

The Residual Network

Definition Given a flow $f$ in $G$, the residual network $G_f$ has the same vertices, and for each edge $e = (u,v)$ of $G$:
  • a forward edge $(u,v)$ with residual capacity $c(e) - f(e)$, if positive;
  • a backward edge $(v,u)$ with residual capacity $f(e)$, if positive.

The Residual Network

$G_f$ has at most $2|E|$ edges — same order of size as $G$.

Residual Network of the Greedy Flow

Path $s \to 1 \to 3 \to 2 \to 4 \to t$ has residual capacity $\min(5,3,8,3,5) = 3$.

Augmenting to Value 21

Push $3$ units along the path: forward edges gain $3$ units of flow, the backward edge $3 \to 2$ removes $3$ units from edge $2 \to 3$.

The New Residual Network

So there is no st-path in $G_f$. Coincidence that this means we are optimal? Not at all — that is the next part.

Augmenting Paths

Definition An augmenting path for a flow $f$ is an st-path $P$ in the residual network $G_f$. Its residual capacity $c_f(P)$ is the minimum residual capacity of its edges.

Augmenting Paths

Key Fact If $f$ has an augmenting path $P$, then pushing $c_f(P)$ units along $P$ (add on forward edges, subtract on backward edges) yields a valid flow of value $$|f| + c_f(P) \;>\; |f|.$$

Feasibility check: forward edges stay $\le c(e)$ by definition of residual capacity; backward edges stay $\ge 0$; conservation holds because each internal path vertex gets $+$ and $-$ adjustments that cancel.

The Ford-Fulkerson Method

FordFulkerson(G, s, t, c):
  initialise f(e) = 0 for all e            // start from the zero flow
  while there is an st-path P in G_f:
      choose an augmenting path P
      augment f by c_f(P) along P             // value strictly increases
  return f

Called a method rather than an algorithm: it does not specify which augmenting path to choose. Different choices give different running times.

Two questions we must answer:

  • Does the loop terminate?
  • When it stops (no augmenting path), is $f$ actually a maximum flow?

Max-Flow = Min-Cut

st-Cuts

Definition An st-cut is a partition $(X, Y)$ of the vertices with $s \in X$ and $t \in Y$. Its capacity is $\textstyle\sum_{e \in \delta^+(X)} c(e)$ — the total capacity of edges leaving $X$.

st-Cuts

Other examples:

  • $X = \{s\}$ has capacity $10 + 8 + 5 = 23$.
  • $X = \{s, 1, 2\}$ has capacity $5 + 3 + 3 + 10 + 5 = 26$.

Note: edges entering $X$ do not count.

Flow Across a Cut

Flow Fact For any flow $f$ and any st-cut $(X, Y)$: $$|f| \;=\; \sum_{e \in \delta^+(X)} f(e) \;-\; \sum_{e \in \delta^-(X)} f(e).$$ The value of the flow equals the net flow crossing any st-cut.

Flow Across a Cut

Proof. Sum the quantity $\sum_{e \in \delta^+(v)} f(e) - \sum_{e \in \delta^-(v)} f(e)$ over all $v \in X$.

  • By conservation, every $v \ne s$ contributes $0$; the vertex $s$ contributes exactly $|f|$.
  • Edges with both endpoints in $X$ appear once with $+$ and once with $-$: they cancel.
  • What survives: edges leaving $X$ (counted $+$) and edges entering $X$ (counted $-$). $\blacksquare$

Weak Duality: Flow ≤ Cut

For every flow $f$ and every st-cut $(X,Y)$:

$$\begin{aligned} |f| \;&=\; \sum_{e \in \delta^+(X)} f(e) - \sum_{e \in \delta^-(X)} f(e)\\ &\le\; \sum_{e \in \delta^+(X)} f(e) \;\le\; \sum_{e \in \delta^+(X)} c(e). \end{aligned}$$

Corollary $\max$ st-flow $\;\le\;$ $\min$ st-cut capacity.

Weak Duality: Flow ≤ Cut

So a cut of capacity $21$ certifies that our flow of value $21$ is maximum — cuts are optimality certificates for flows.

Remarkably, a matching cut always exists.

The Max-Flow Min-Cut Theorem

Theorem For an st-flow $f$, the following are equivalent:
  1. $f$ is a maximum flow;
  2. there is no augmenting path in $G_f$;
  3. there is an st-cut of capacity exactly $|f|$.

In particular: maximum st-flow value $=$ minimum st-cut capacity.

Plan: $(1) \Rightarrow (2)$ and $(3) \Rightarrow (1)$ are quick; the heart of the proof is $(2) \Rightarrow (3)$.

The Two Easy Implications

Theorem For an st-flow $f$, the following are equivalent:
  1. $f$ is a maximum flow;
  2. there is no augmenting path in $G_f$;
  3. there is an st-cut of capacity exactly $|f|$.
(1) ⇒ (2) Contrapositive: if $G_f$ has an augmenting path $P$, pushing $c_f(P) > 0$ along it gives a strictly larger flow — so $f$ was not maximum.

The Two Easy Implications

Theorem For an st-flow $f$, the following are equivalent:
  1. $f$ is a maximum flow;
  2. there is no augmenting path in $G_f$;
  3. there is an st-cut of capacity exactly $|f|$.
(3) ⇒ (1) By weak duality every flow value is at most the capacity of every cut. If some cut has capacity exactly $|f|$, no flow can beat $f$: it is maximum.

Remaining: $(2) \Rightarrow (3)$ — from “no augmenting path” we must construct a cut of capacity $|f|$.

(2) ⇒ (3): Reading a Cut off Gf

Suppose $G_f$ has no st-path. Let $X = \{\,v : v \text{ reachable from } s \text{ in } G_f\,\}$ and $Y$ the rest.

  • $s \in X$ by definition, and $t \in Y$ since there is no st-path: $(X,Y)$ is an st-cut.
  • No residual edge crosses from $X$ to $Y$ — otherwise the head would be reachable too.

(2) ⇒ (3): Reading a Cut off Gf

Our example after augmenting to $21$: the vertices reachable from $s$ in $G_f$ were $X = \{s, 1\}$.

(2) ⇒ (3): Reading a Cut off Gf

No residual edge leaves $X$ — in $G$ this says two things:

(a) No forward residual edge leaves $X$: every edge of $G$ leaving $X$ is saturated, $f(e) = c(e)$.
(b) No backward residual edge leaves $X$: every edge of $G$ entering $X$ carries zero flow, $f(e) = 0$.

In our example: after augmenting to $21$, the vertices reachable from $s$ in $G_f$ are exactly $\{s, 1\}$ — the dashed cut from before, with capacity $21$.

(2) ⇒ (3): Finishing the Computation

Apply the Flow Fact to the cut $(X, Y)$ we just built:

$$\begin{aligned} |f| \;&=\; \sum_{e \in \delta^+(X)} f(e) - \sum_{e \in \delta^-(X)} f(e)\\ &\overset{(b)}{=}\; \sum_{e \in \delta^+(X)} f(e) \;\overset{(a)}{=}\; \sum_{e \in \delta^+(X)} c(e). \end{aligned}$$

So the capacity of $(X,Y)$ is exactly $|f|$ — statement (3). $\blacksquare$

(2) ⇒ (3): Finishing the Computation

Consequence When Ford-Fulkerson stops, the flow is maximum. And the vertices reachable from $s$ in the final residual network hand us a minimum cut for free.

A Second Proof Is Coming

Preview In Week 10 we will see a second, completely different proof of max-flow $=$ min-cut, via LP duality: flows and cuts are optimal solutions of a primal-dual pair of linear programs.

Same theorem, two proofs, two generalisations: the residual-graph proof gives algorithms; the LP proof places the theorem inside a much bigger duality landscape.

Integral Capacities: Termination

Theorem If all capacities are integers, Ford-Fulkerson terminates, and it outputs a maximum flow that is integral (every $f(e)$ is an integer).

Why. Starting from the zero flow, all capacities in $G_f$ stay integral, so each augmentation is by an integer amount, i.e. increases $|f|$ by at least $1$. With $F = $ max-flow value, the loop runs at most $F$ times.

Integral Capacities: Termination

Moreover the flow found is built from integer augmentations, so it is integral.

Careful With irrational capacities Ford-Fulkerson can actually fail to terminate!

How Fast Is Ford-Fulkerson?

Runtime Each iteration (find a path in $G_f$ by BFS/DFS, augment) takes $O(|E|)$ time, so on integer capacities Ford-Fulkerson runs in $O(F \cdot |E|)$ time.

Two loose ends:

  • The bound depends on the flow value $F$, which can be exponential in the input size — fixed by Edmonds-Karp next.
  • Integrality looks like a technicality, but it is exactly what our applications will exploit.

Edmonds-Karp

Choosing Paths Wisely

$O(F \cdot |E|)$ is not polynomial in the input size: a capacity of $10^9$ fits in 30 bits but may force $10^9$ augmentations if paths are chosen badly.

Edmonds-Karp (1970) Run Ford-Fulkerson, always choosing an augmenting path with the fewest edges. The running time is $O(|V| \cdot |E|^2)$ — independent of the capacities.

Choosing Paths Wisely

  • A fewest-edges st-path in $G_f$ is found by BFS (ignore capacities) in $O(|E|)$ time per round.
  • So it suffices to show: the number of rounds is $O(|V| \cdot |E|)$.

BFS Levels of Gf

Fix the current $G_f$ and let $L_i$ be the vertices at distance $i$ from $s$ (BFS layers), with $t \in L_d$.

Every edge of $G_f$ goes at most one level forward (BFS property), so a shortest st-path is $s - v_1 - \dots - v_{d-1} - t$ with $v_i \in L_i$.

Distances Never Decrease

What can one shortest-path augmentation change in $G_f$?

  • Augmenting on $(v_i, v_{i+1})$ may delete that edge (if saturated) and may create the reverse edge $(v_{i+1}, v_i)$.
  • So every new edge points from some $L_{i+1}$ back to $L_i$ — one level backwards.
  • A path using a backward edge wastes at least two steps: adding such edges cannot create an st-path shorter than $d$.
Key Fact Under shortest-path augmentation, the st-distance in $G_f$ never decreases.

Counting the Rounds

  • Each augmentation saturates at least one edge of the path (the bottleneck), deleting an $L_i \to L_{i+1}$ edge from $G_f$.
  • While the distance stays equal to $d$, shortest paths only use $L_i \to L_{i+1}$ edges — and new edges never have this form. There are at most $|E|$ such edges: each edge of $G$ yields two opposite residual edges, at most one of which is level-forward. So after at most $|E|$ augmentations, no shortest path of length $d$ remains: the distance strictly increases.

Counting the Rounds

  • The distance is an integer between $1$ and $|V| - 1$, so it can increase at most $|V|$ times.
  • At most $|E|$ augmentations per distance value, at most $|V|$ distance values.
Theorem Edmonds-Karp performs $O(|V| \cdot |E|)$ augmentations; with $O(|E|)$ BFS per round the total running time is $O(|V| \cdot |E|^2)$ — for arbitrary real capacities.

Applications

Application 1: Matching

Definition A matching is a set of edges $M$ such that each vertex touches at most one edge of $M$. A matching covering all vertices is perfect.

In Weeks 3-4 we solved maximum matching on trees by DP and greedy. In a bipartite graph (parts $L$, $R$, all edges between) it models assigning jobs to applicants.

Matching as a Flow Problem

Build a flow network:

  • direct all edges from $L$ to $R$, capacity $1$;
  • add source $s$ with edges $s \to \ell$ of capacity $1$ for every $\ell \in L$;
  • add sink $t$ with edges $r \to t$ of capacity $1$ for every $r \in R$.
Claim max flow value $=$ maximum matching size.

Proof: Flow ≥ Matching

Take any matching $M$.

  • Each matching edge $(\ell, r)$ gives a path $s \to \ell \to r \to t$.
  • Because $M$ is a matching, these paths are edge-disjoint (each $\ell$ and each $r$ is used once).
  • Sending one unit along each path is a valid flow of value $|M|$.
Half Done max flow $\ge$ max matching.

Proof: Flow ≤ Matching — via Integrality

All capacities are $1$, so by the integrality theorem there is a maximum flow with values in $\{0, 1\}$.

Claim The $L\!\to\!R$ edges carrying flow $1$ form a matching of size $|f|$.

Proof: Flow ≤ Matching — via Integrality

Claim The $L\!\to\!R$ edges carrying flow $1$ form a matching of size $|f|$.
  • $\ell \in L$ receives at most $1$ unit (from $s$), so by conservation at most one flow-$1$ edge leaves $\ell$.
  • $r \in R$ can send at most $1$ unit (to $t$), so at most one flow-$1$ edge enters $r$.

So every vertex touches at most one selected edge: the selected $L\!\to\!R$ edges form a matching.

Proof: Flow ≤ Matching — via Integrality

  • The number of selected edges is the flow crossing the cut $(\{s\} \cup L,\; R \cup \{t\})$, which is $|f|$. $\blacksquare$
Runtime $F \le |V|$, so plain Ford-Fulkerson already solves bipartite matching in $O(|V| \cdot |E|)$ time. Integrality did the heavy lifting.

Kőnig's Theorem

Theorem (Kőnig, 1931) If $G$ is bipartite, then $\nu(G) = \tau(G)$: the maximum matching size equals the minimum vertex cover size.

Weak duality (Week 3): $\nu(G) \le \tau(G)$ in every graph, since a cover needs a distinct vertex for each edge of a matching.

Week 3 proved the bipartite case with alternating paths. Today we read a cover off a minimum cut of the matching network.

Kőnig via Min Cut

Plan: turn a minimum cut of the matching network into a vertex cover of the same size, by associating each cut edge with a vertex:

  • cutting $s \to \ell$ costs $1$  $\leftrightarrow$  put $\ell$ in the cover;
  • cutting $r \to t$ costs $1$  $\leftrightarrow$  put $r$ in the cover;
  • cutting a middle edge $\ell \to r$: two candidates, $\ell$ or $r$, and nothing in the cut says which. Either works, but the association is no longer forced.

Kőnig via Min Cut

We would like the association to be forced, and exact.

The role of $\infty$ Give the middle edges capacity $\infty$. A cut using one costs $\infty$ while $\{s\}$ costs $|L|$, so a minimum cut uses only $s$- and $t$-edges. Each of these is associated with one vertex, so the cut maps to a set of vertices of size exactly its capacity.

The max flow is unchanged: each $\ell$ still receives at most $1$ unit.

Kőnig via Min Cut

Take a minimum cut $X \ni s$ of the network with $\infty$ middle edges; let $X_L = X \cap L$ and $X_R = X \cap R$. For $S \subseteq L$, write $N(S)$ for its set of neighbours in $R$.

Kőnig via Min Cut

Let $C = (L \setminus X_L) \cup X_R$: the vertices associated with the crossing edges.

$C$ is a vertex cover: an edge missing $C$ would run from $X_L$ to $R \setminus X_R$ — and there are none.

Kőnig via Min Cut

A minimum cut $X$ gave a vertex cover $C$ with $|C| = $ capacity of $X$.

Conclusion
$$\underbrace{\tau}_{\text{min vertex cover}} \le |C| = \text{min cut} = \text{max flow} = \underbrace{\nu}_{\text{max matching}}$$
With weak duality $\nu \le \tau$, thus $\nu = \tau$. $\blacksquare$

Perfect Matchings and an Obstacle

When does a bipartite graph with $|L| = |R| = n$ have a perfect matching? Our example has none:

In general: a perfect matching forces $|N(S)| \ge |S|$ for every $S \subseteq L$, since $S$ must be matched into $N(S)$.

Hall's Theorem

Theorem (Hall) A bipartite graph with $|L| = |R| = n$ has a perfect matching if and only if $|N(S)| \ge |S|$ for every $S \subseteq L$.

A set with $|N(S)| < |S|$ is the only obstacle to a perfect matching.

We just saw necessity. Sufficiency is a corollary of Kőnig: we show every vertex cover has at least $n$ vertices.

Hall's Theorem: a Corollary

Assume $|N(S)| \ge |S|$ for all $S \subseteq L$. Let $C$ be a minimum vertex cover (orange) and $S = L \setminus C$, the uncovered part of $L$.

Hall's Theorem: a Corollary

Now count $C$, column by column:

  • $|L \cap C| = n - |S|$, since $S$ is the rest of $L$;
  • $|R \cap C| \ge |N(S)| \ge |S|$, by the picture and by Hall's condition.

So $|C| \ge (n - |S|) + |S| = n$: every vertex cover has at least $n$ vertices. And $L$ itself is a cover of size $n$, so $\tau = n$.

Conclusion By Kőnig, $\nu = \tau = n$, thus there is a perfect matching. $\blacksquare$

Matrix Rounding via Integrality

  • The fractional entries themselves are a flow: put $a_{ij}$ on edge $R_i \to C_j$. Conservation at $R_i$ / $C_j$ is exactly the row / column sum. Value $= 0.7 + 0.8 + \dots = 5$, the total sum.
  • The cut $X = \{s\}$ has capacity $2+1+2 = 5$, so this flow is maximum.
  • All capacities are integers $\Rightarrow$ there is an integral max flow of value $5$: each middle edge carries $0$ or $1$.
  • Those $0/1$ values are the rounded matrix — row and column sums are forced by saturation of the $s$- and $t$-edges. The rounding always exists.

Summary

  • Max flow: route as much as possible from $s$ to $t$ under capacities; greedy path-packing fails.
  • Residual networks let augmenting paths undo earlier decisions; Ford-Fulkerson repeats until no augmenting path remains.
  • Max-flow $=$ min-cut: no augmenting path $\Rightarrow$ the reachable set of $G_f$ is a cut of capacity $|f|$. Cuts certify optimality.

Summary

  • Edmonds-Karp: BFS-shortest augmenting paths give $O(|V| \cdot |E|^2)$, independent of capacities.
  • Integrality turns flows into combinatorics: bipartite matching, Kőnig's and Hall's theorems, matrix rounding.
