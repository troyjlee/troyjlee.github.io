Each markdown file in the `_notes/` folder becomes a page listed on the [notes](/notes/) index, ordered by the `order` field in its front matter.

To start a series on a topic, create one file per page of the series here. Math works out of the box: inline $$E = mc^2$$ and display mode

$$
\left(\sum_{i=1}^n a_i b_i\right)^2 \leq \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)
$$

as do code blocks, images, and everything else Markdown supports.
